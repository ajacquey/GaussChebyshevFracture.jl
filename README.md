## Installation

You can install `GaussChebyshevFracture` directly from the `Pkg` REPL:

```
pkg> add GaussChebyshevFracture
```

## Related publication
`GaussChebyshevFracture` provides a set of numerical methods to solve fracture problems. 
Its implementation and formulation is based on the following publication:

- Viesca, R.C. and Garagash, D. Numerical methods for coupled fracture problems. Journal of the Mechanics and Physics of Solids, 113 (2018) 13–34. [![https://doi.org/10.1016/j.jmps.2018.01.008]](https://doi.org/10.1016/j.jmps.2018.01.008).
